# Annual review + feature-launch review process (draft)

## Cadence
- Annual: full doc review (ToS, Privacy, Provider Agreement, Refund, Community, Disclaimer, Claims, Grievance, consent texts).
- Per feature launch: new category -> new addendum; new data flow -> DPIA update; new vendor -> vendor list update.

## Checklist per review
- [ ] All docs versioned (vX.Y, effective date).
- [ ] Re-acceptance flow triggered on material changes.
- [ ] Compliance register updated (owner/evidence/review date).
- [ ] Translations reviewed (Hindi + regional).
- [ ] Plain-language summaries updated.

## Owner
- Compliance lead + legal counsel (retainer).

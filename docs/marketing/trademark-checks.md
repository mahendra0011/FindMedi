# Trademark/copyright checks (draft)

## Pre-launch checklist
- [ ] Brand name "FindMedi" trademark search (India + target markets).
- [ ] Logo originality check (no third-party marks).
- [ ] Font licenses: Inter, Plus Jakarta Sans, Noto Sans (all OFL — OK).
- [ ] Image licenses: all stock images licensed or original.
- [ ] Music/audio: licensed or royalty-free.
- [ ] Third-party SDK licenses reviewed (MIT/Apache/BSD — OK).

## Process
- Legal counsel conducts final clearance before launch.

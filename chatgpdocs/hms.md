# 54. ROLE-WISE PERMISSIONS — SABSE IMPORTANT

Sirf dashboard alag hona kaafi nahi hai. **Har role ko data aur actions ki permissions bhi alag deni hongi.**

Permissions ko in actions mein divide karo:

* View
* Create
* Edit
* Delete
* Approve
* Print
* Export
* Sign
* Assign
* Refund
* Reverse
* Dispense
* Verify
* Finalize

### Example

| Action                | Doctor                               | Nurse                         | Receptionist      | Cashier                       | Hospital Admin                              |
| --------------------- | ------------------------------------ | ----------------------------- | ----------------- | ----------------------------- | ------------------------------------------- |
| Register Patient      | Permitted, if authorized             | Limited                       | Yes               | Limited                       | Authorized access                           |
| View Clinical History | Authorized patients                  | Assigned / permitted patients | Minimum necessary | Generally unnecessary         | Only when authorized                        |
| Write Clinical Notes  | Yes, within scope                    | Nursing notes                 | No                | No                            | Only if clinically qualified and authorized |
| Sign Prescription     | Authorized doctor                    | No                            | No                | No                            | Only if authorized clinician                |
| Record Vitals         | Yes                                  | Yes                           | Normally no       | No                            | According to role                           |
| Create Invoice        | According to workflow                | No                            | Limited           | Yes                           | Authorized access                           |
| Collect Payment       | If assigned and permitted            | No                            | Limited           | Yes                           | Authorized access                           |
| Approve Refund        | Normally no                          | No                            | Normally no       | According to delegated limits | According to authority                      |
| Dispense Medicine     | No, unless separately authorized     | No                            | No                | No                            | Only authorized pharmacy staff              |

Role ke saath **branch scope, department scope, assigned patients aur individual permissions** bhi check karna zaroori hai.

## Final recommendation

**Aap ek hi HMS application mein role-based dashboard engine banao.** Har role ke liye alag software develop karne ki zaroorat nahi hai.

Har dashboard mein ye 4 cheezein fix rakho:

**1. Overview Cards:** Us role ke important numbers.

**2. Work Queue:** Abhi kya pending hai aur kis par action lena hai.

**3. Quick Actions:** user apna comman kaam easily ker saket he ust nt need ofr that the vidoe 

**4. Alerts & Notifications:** Sirf relevant, actionable aur permission-appropriate alerts.

Shuruat mein **Hospital Admin, Doctor, Nurse, Receptionist, Admission/Bed Manager, Emergency, Billing/Cashier, Lab, Radiology, Pharmacy aur Insurance** ke dashboards implement karna practical rahega. Baaki specialist dashboards ko un departments ki availability aur hospital ki requirements ke according enable karo.

Is structure se system ek chhote hospital se lekar multi-department, multi-branch hospital network tak scale karne ke liye achha foundation dega.

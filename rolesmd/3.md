# 02 — Listing Cards (Design Spec)

> **Existing (✅):** `DoctorCard, HospitalCard, ClinicCard, DiagnosticCenterCard, PharmacyCard, AssistantCard, LawyerCard`.
> Fields jo already use hote hain: rating, reviews, fee, availability, qualifications, experience, languages, distance, city, address, verified, badges, insuranceAccepted, accreditations, emergency, homeCollection, open-now, Book / View / Call.
>
> **Goal:** ek **base card system** + type-wise variants, taaki 25+ entity types ka UI consistent rahe.

---

## 1. Base card anatomy (sab cards me common)

```
┌────────────────────────────────────────────────────┐
│ [Image/Avatar]  Title                  [♡ Save]    │
│  (badge overlay) Subtitle / Category               │
│                  ★ 4.6 (312)  · 2.4 km · Open now  │
│                  Key facts row (2–4 chips)         │
│                  Price / Fee line                  │
│  ───────────────────────────────────────────────── │
│  Trust badges        |   Next availability         │
│  [Secondary CTA]            [Primary CTA]          │
└────────────────────────────────────────────────────┘
```

| Zone | Content | Rules |
|---|---|---|
| **Media** | Photo/logo/avatar (lazy, WebP, fixed aspect), overlay badge (Sponsored / Govt / New / 24x7) | Alt text; fallback initials; no PHI in images |
| **Title** | Name (max 2 lines), verified tick | Truncate with tooltip |
| **Subtitle** | Specialty / type / system | Canonical category label (localized) |
| **Meta row** | ★ rating (hide if < 3 reviews → "New"), distance, open-now/closing time | Distance only if location permission |
| **Key facts** | 2–4 chips (see per-type) | Never more than 4 |
| **Price** | "₹500 consult" / "from ₹299" / "Free" / "₹/day" | Currency + inclusive-of-tax note on detail |
| **Trust row** | Verified · NABH/NABL · PM-JAY · Women-friendly · Govt · Background-checked | Max 3 visible + "+n" |
| **Availability** | "Next: Today 5:30 PM" / "Available now" / "Waitlist" | From real slots, cached 1–2 min |
| **CTAs** | Primary (Book / Order / Join / Register / Call), Secondary (View / Directions / Save) | One primary only |
| **Save/Compare** | ♡ saved (✅ favorites), compare checkbox (2–3 items) | — |
| **Sponsored label** | "Sponsored" clearly (FeaturedListing ✅) | Ads disclosure; no medical-claim boosts |

**States:** loading skeleton · default · hover/focus · saved · unavailable ("Not accepting bookings") · closed · suspended (hidden) · error. **A11y:** card = single focus target with labelled actions, 44px touch targets, color-contrast AA, screen-reader text for rating/distance.

**Privacy rule:** cards **public data** hi dikhate hain. T1 providers ke patient counts/medical stats nahi; sensitive categories (sexual health, de-addiction, mental health) me **discreet mode** (neutral labels, no auto-suggest in "recently viewed").

### 2.2 Hospital card ✅
Name, type chips (Multi-specialty / Govt / Trust), ownership, ★, distance, open/24x7, **Emergency** tag, beds available hint (optional, from live bed data), top 3 specialties + "+n", accreditations (NABH), **insurance/PM-JAY** chips, ambulance available, CTAs: **Book appointment · Directions · Call**.

### 2.3 Clinic card ✅
Name, clinic type (Polyclinic/Specialty), doctors count, specialties (3), ★, distance, today's timings, fee range, CTAs: **Book · View**.

### 2.4 Diagnostic centre card ✅
Name, services chips (Pathology / Imaging / Home collection), **NABL** badge, ★, distance, TAT ("Reports in 6 h"), **home collection** tick + fee, popular tests price ("CBC ₹199"), open-now, CTAs: **Book test · Call**.

### 2.5 Pharmacy card ✅ (upgrade — currently View only)
Name, type (Retail / Hospital / Jan Aushadhi / 24x7), ★, distance, open-now, **delivery ETA + fee**, min-order, Rx accepted, offers ("20% off generics"), **Jan Aushadhi** badge, CTAs: **Order / Upload Rx · View**.

### 2.6 Assistant/attendant card ✅
Photo, name, experience, skills chips, languages, price/hr or per shift, ★, police-verified ✅ badge, availability today, gender, CTAs: **Book · View**.

### 2.7 Lawyer card ✅
Name, bar council + state, practice-area chips, courts, experience, consultation fee, languages, ★, modes (chat/video/in-person), CTAs: **Book consultation · View**.

### 2.8 Counsellor / Psychologist card ✅ (mind module)
Name, type (Professional / Peer mentor) with **clear label**, concerns chips (3), modalities, languages, mode icons, response time ("replies in 2 h"), price/session, ★, "First session free?" tag, **discreet mode**. CTA: **Book session**. Peer mentor card me banner: "Peer support — not clinical care".

### 2.9 🆕 Dentist / Dental clinic card
Name, specialties (Ortho, Implants, RCT, Paedo), chairs/sterilisation badge, ★, distance, consult fee, **price chips** ("Cleaning ₹600", "RCT from ₹3,000"), emergency dental tag, EMI available, CTAs: **Book · Directions**.

### 2.10 🆕 Eye hospital / Optical card
Eye hospital: services (Cataract, LASIK, Retina), ★, distance, camps tag. Optical: brands, **free eye-test** tag, delivery, price from. CTAs: **Book eye test · Directions**.

### 2.11 🆕 AYUSH clinic / practitioner card
System tag (Ayurveda/Homeopathy/Unani…), specialty (Panchakarma, Skin, Paediatric), practitioner council-verified, ★, fee, modes, in-house medicines tag. CTA: **Book**.

### 2.12 🆕 Physiotherapist / Rehab card
Focus chips (Neuro, Ortho, Sports…), home-visit tick + radius, session price, package price ("10 sessions ₹6,000"), ★, equipment available, CTA: **Book session / Home visit**.

### 2.13 🆕 Dietitian card
Focus chips (Diabetes, PCOS, Weight…), plan types (4-wk, 12-wk), diet-plan sample badge, languages, modes, price, ★, CTA: **Book consult / View plans**.

### 2.14 🆕 Nurse / home-nursing card
Skills chips (IV, wound care, ICU-at-home), shift options (4h/12h/24h), price, police-verified, nursing-council badge, gender, languages, area covered, CTA: **Book**.

### 2.15 🆕 Yoga card (teacher/studio/camp)
Style chips (Hatha, Vinyasa, Prenatal), mode (studio/online/home), batch times, trial class ("1st class free"), price/month, level (beginner), women-only batch tag, ★, certification badge (YCB), CTA: **Book trial / Join batch**.

### 2.16 🆕 Gym / fitness card
Photo gallery strip, facilities icons (cardio, weights, pool, steam), trainers count, plans (monthly ₹..), peak-hours/crowd indicator, women-only hours, trial pass, distance, ★, CTA: **Get trial pass / Buy membership**.

### 2.17 🆕 Wellness centre / spa card
Therapies chips, price from, hygiene badge, ★, gender-specific slots, CTA: **Book session**. (No disease-cure claims.)

### 2.18 🆕 Equipment rental/sale card
Product image, name, spec chip (e.g., "5L oxygen concentrator"), **Rent ₹/day · Buy ₹**, deposit, delivery ETA, availability ("3 in stock"), sanitised ✓, warranty, CTA: **Rent / Buy**.

### 2.19 🆕 Product card (supplement / health-food / skincare / device)
Image, brand, name, size/pack, **MRP / price / % off**, ★, tags (Vegan, Sugar-free, FSSAI ✓ / CDSCO ✓), Rx-required badge (red) when applicable, delivery ETA, CTA: **Add to cart**. Claims restricted: no "cures…", show "Not a substitute for medical advice" on supplement cards.

### 2.20 🆕 Medicine card (existing catalog, standardised)
Name + strength, generic/salt, manufacturer, pack size, MRP/price, **Rx schedule badge** (OTC / Rx / H1), cold-chain icon, substitute count ("5 cheaper generics"), stock, CTA: **Add / Upload Rx**.

### 2.21 🆕 Health package card (✅ existing data)
Package name, category chip (Cardiac, Women, Senior…), tests count, "includes" top 4, home collection, fasting required, TAT, price + strikethrough, "Popular", lab name/NABL, CTA: **Book**.

### 2.22 🆕 Event / camp / workshop card
Banner, title, type chip (Free checkup camp / Webinar / CPR training / Blood drive), **date-time**, venue/online, organiser + partner facility, **Free / ₹fee**, seats left ("23 left"), registration deadline, language, CTA: **Register**. States: upcoming · filling fast · full (waitlist) · ongoing · ended (report).

### 2.23 🆕 Program / membership card
Name (Diabetes care 3-month, Prenatal yoga, Gym 6-mo), duration, what's included (doctor + dietitian + tracking), price/EMI, trial, outcome stats (aggregate, anonymised), CTA: **Enroll**.

### 2.24 🆕 Government facility card
PHC/CHC/UPHC/Arogya Mandir/Jan Aushadhi, **Govt** badge, free-services chips (OPD, vaccination, ANC), timings, OPD-days, address + map, helpline, **"Information only"** if no booking, CTA: **Directions · Call · Get token** (if OPD token supported ✅).

### 2.25 🆕 Blood bank / donor card
Bank name, licence ✓, **availability by group** (heatmap chips), components, 24x7, distance, CTA: **Request blood / Call**. Donor cards: group, last donated (hide exact), availability toggle; contact masked until accepted.

### 2.26 🆕 Ambulance operator card
Types (BLS/ALS/NICU/Mortuary), ETA, base fare + per-km, 24x7, GPS-tracked ✓, oxygen/ventilator ✓, CTA: **Call now / Book** (SOS ✅ flow).

### 2.27 🆕 Counselling / support-group card
Topic, schedule, host (verified), mode, free/paid, anonymity option, group size, moderation badge, CTA: **Join**.

### 2.28 🆕 Content card (article/video/course)
Thumbnail, title, specialty tag, **doctor-reviewed ✓**, read-time/duration, language, CTA: **Read/Watch/Enroll**.

| Variant | Use |
|---|---|
| **List (horizontal)** | Search results, desktop |

| **Sponsored** | Same layout + "Sponsored" label |
| **Skeleton** | Loading |

## 4. Sorting & filter chips shown with cards

Sort: Relevance · Nearest · Rating · Price low→high · Earliest slot · Experience · Most booked.
Quick chips: Open now · Today · Home visit · Video · Women provider · Govt · PM-JAY/Insurance · Under ₹500 · 24x7 · Parking/wheelchair · Language.

## 5. Data contract (what API must give per card)

```
id, type, slug, name, imageUrl, verified, ratingAvg, ratingCount, distanceKm, openNow, nextSlotAt,
priceFrom/fee{mode:amount}, badges[], schemes[], languages[], city/area, geo{lat,lng},
specialty/category{code,label}, modes[], isSponsored, isSaved
```
- **Public-safe DTO only** (no phone/email/license numbers on cards); `.select()` explicit.
- Pagination `limit ≤ 50`; cache public listings (CDN) but **never** personalised data (saved state via separate call).

## 6. Anti-patterns to avoid

- Hardcoded counts ("45+ doctors") → DB aggregates (🐞 `Home.tsx`)
- "Best/No.1/100% cure" labels, unverified claims
- Showing a rating with <3 reviews as a number
- Mixing sponsored and organic without label
- Showing exact home address of home-based practitioners (show area only)
- Auto-suggesting sensitive categories in public/"recently viewed"

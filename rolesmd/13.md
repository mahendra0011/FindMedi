## 10. Flow maps (high level)

```
Discovery:   Home → Search → Results → Detail/Profile → Book → Pay → Confirm → Visit → Review
Join:        Join → Type → Wizard → Submit → (Review/Needs info) → Approved → Activation checklist → Live
Order:       Cart → Rx check → Pay → Track → Deliver(OTP) → Return/Refund
Event:       Event → Register → Ticket → Check-in → Attend → Feedback
Membership:  Plan → Trial → Pay/Mandate → Active → Freeze/Renew/Cancel
Emergency:   SOS → Dispatch → Track → Hospital pre-alert
Dispute:     Report → Ticket → Evidence → Decision → Appeal
```

## 11. Usability test plan (before building everything)
- 5–8 users per persona (elderly, parent, young adult, caregiver) on **paper/Figma prototypes**: find a dentist, book, pay, find report.
- 5 provider interviews (clinic owner, lab, pharmacy, gym, nurse agency): complete join wizard on mobile.
- Test in **Hindi** and one regional language; test on low-end Android + 3G throttle.
- Metrics: task success, time-on-task, errors, SUS score; iterate before engineering.

# 03 — Facility Detail Pages (Spec)

> **Existing (✅):** `HospitalProfile` (Doctors, Emergency, Accreditations, Insurance Accepted, Suggested Hospitals), `ClinicDetail` (Doctors, Insurance Accepted, Suggested Clinics), `DiagnosticCenterDetail` (Tests, Timings, Contact), `ImagingCenterDetail`, `MedicineStoreDetail` (Nearby Stores), `TechnicianDetail`.
> **Pattern:** har page ke 1000–1800 lines hain → alag-alag copy. Naye types ke liye **ek `FacilityDetailLayout` + section registry** banao: har type apne sections choose kare.

---

## 1. Common layout (sab facility pages)

```
[Breadcrumb: Home › City › Category › Name]
[Hero: gallery · name ✓ · type chips · ★ · open-now · distance · Save · Share · Report]
[Sticky action bar: Book / Order / Call / Directions / WhatsApp?]
[Tabs / Sections: Overview · Services · Doctors/Staff · Reviews · Photos · Policies · FAQ · Location]
[Right rail (desktop): booking widget · timings · contact · schemes accepted]
[Footer blocks: Similar nearby · Recently viewed · Disclaimer]
```

### 1.1 Common sections

| Section | Content |
|---|---|
| **Hero** | 5–10 photos (lightbox), video tour (optional), name, verified badge + "Verified on <date>", type/ownership/system chips, ★ avg (n), open-now + today's hours, area + distance, tagline |
| **Sticky action bar** | Primary CTA (Book/Order/Join), Call (click-to-call, masked/relay number optional), Directions (Maps), Save, Share |
| **About / Overview** | Description (500 chars + "read more"), established year, size (beds/chairs/trainers), languages spoken, key highlights (4–6 icons) |
| **Services** | From category tree: name, short desc, duration, price/from-price, modes, "Book" per service |
| **Practitioners / Staff** | Cards (doctor/trainer/therapist) with specialty, experience, next slot → opens profile (file 04) |
| **Timings** | Weekly table, holiday exceptions, 24x7 flag, "Open now/Closes at", emergency hours |
| **Pricing & Packages** | Price list, packages, "Inclusive of GST", discounts, EMI info |
| **Insurance & Schemes** | PM-JAY, CGHS, ESI, ECHS, private insurers/TPA, cashless Y/N, "Verify with the facility before visiting" |
| **Facilities & Amenities** | Icons (parking, wheelchair, lift, cafeteria, pickup, Wi-Fi, prayer room, lodging, women-only hours) |
| **Accreditations & Licences** | NABH/NABL/ISO badges (+ cert expiry), licence verification note (numbers partial-masked, "view verification") |
| **Reviews & Ratings** | Rating histogram, filters (service, recent, with photo), verified-visit badge, provider replies, report review |
| **Photos / Videos** | Categories (exterior, reception, equipment, rooms) |
| **Location & Getting there** | Map pin, address, landmarks, public transport/metro, parking, "Get directions", street-view link |
| **FAQ** | Provider-managed + platform defaults |
| **Policies** | Cancellation/reschedule, refund, payment methods, privacy/consent note |
| **Report / Claim** | "Report incorrect info", "Claim this listing" (for unclaimed govt/imported listings) |
| **Similar nearby** | 3–6 cards (✅ "Suggested Hospitals/Clinics") |
| **Disclaimer** | "Information provided by the facility; FindMedi isn't a medical provider" |

### 1.2 SEO & sharing
- URL: `/<city>/<category>/<slug>` (e.g., `/bhopal/dental-clinic/smile-care`)
- `<title>`/meta description templated; **JSON-LD**: `MedicalOrganization` / `Physician` / `LocalBusiness` + `openingHoursSpecification`, `aggregateRating` (only when ≥ N real reviews)
- OG image, canonical, hreflang (hi/en), sitemap per city+category
- Noindex for pending/suspended/duplicate; no PHI in URLs.

### 1.3 Performance & UX
- Lazy tabs, image CDN, skeletons, <2.5s LCP mobile; offline-friendly "call/directions" actions.
- Sticky mobile bottom bar (Call · Directions · Book).
- Accessibility: landmarks, tab order, alt text, captions.

### 1.4 Trust & safety elements
- "Verified" tooltip explains what was verified (licence, address, practitioners)
- Last updated timestamp; "Provider responded within X hrs"
- Report button (wrong info, unsafe, fake)
- No unverified claims ("best", "100%"); `adClaimsRestricted` categories filtered.

## 2. Type-specific pages

### 2.1 Hospital ✅ (+ upgrades)
Extra sections: **Departments & Specialties** (tree) · **Emergency & Trauma** (24x7, ambulance, ER contact, ICU/NICU) · **Bed info** (types, tariff ranges; live availability if integrated ✅ Bed model) · **Doctors directory** (filter by specialty/day) · **Health packages** ✅ · **International patients/medical-tourism** (P4) · **Insurance desk/TPA** ✅ · **Visitor info** (visiting hours, lodging) · **Quality metrics** (NABH, patient satisfaction — only if verified) · **Blood bank / Pharmacy / Lab in-house** links · **Cashless process steps** · **Telemedicine** option.
CTAs: Book OPD · Emergency call · Ambulance · Get estimate (P3) · Request callback.

### 2.2 Clinic ✅
Doctors with today's slots · Specialty focus · Consult fees by mode · In-clinic services (dressing, vaccination, ECG) · Queue/token status ✅ (OPDToken) · Patient instructions (carry reports, fasting) · Parking.
CTAs: Book · Get token · Call.

### 2.3 Diagnostic lab / imaging ✅
**Test catalogue** (search + category tree ✅) · **Packages** ✅ · **Home collection** (area, slots, fee, phlebotomist info) · **Sample & prep instructions** · **Report TAT + delivery (app/WhatsApp/email)** · **NABL cert** · Machines/technology list (imaging) · **Radiologist/pathologist names** · Price list PDF · Upload prescription to book · Sample tracking explainer.
CTAs: Book test · Book home collection · Upload prescription.

### 2.4 Pharmacy ✅
**Search medicines in this store** · Categories (Rx, OTC, ayurvedic, devices, baby, personal care) · **Offers** ✅ · **Delivery** (radius, ETA, fee, min order, free-delivery threshold) · **Upload prescription** flow explainer · Pharmacist on duty · **Refill reminders** · Cold-chain items · Returns policy ✅ · DL number verified ✓ (masked) · 24x7 flag · Store timings.
CTAs: Order · Upload Rx · Call pharmacist.

### 2.5 🆕 Dental clinic
Services & price list (cleaning, filling, RCT, crowns, implants, braces/aligners, extraction, whitening) · Dentists with sub-specialty · **Before/after gallery** (consent-based; claims policy) · Sterilisation & infection-control note · X-ray/OPG/CBCT in-house · Emergency dental hours · EMI/dental insurance · Kids-friendly tag · Smile-design/consult booking · Aftercare instructions.
CTAs: Book check-up · Book emergency · Get quote.

### 2.6 🆕 Eye hospital / optical
Specialties (cataract, retina, glaucoma, cornea, squint, LASIK) · Surgeons · Technology (phaco, OCT, laser) · **Cataract/LASIK packages** · Free-camp calendar · **Optical shop**: frames/lenses brands, free eye test, try-at-home, prescription upload, pickup/delivery, repairs · Contact-lens fitting.
CTAs: Book eye test · Book surgery consult · Shop spectacles.

### 2.7 🆕 AYUSH clinic / Panchakarma centre
System (Ayurveda/Homeopathy/Unani/Siddha/Naturopathy) · Practitioners with council reg · Treatments (Panchakarma types, therapies) with duration/price · Residential stay (rooms, diet, schedule) · In-house medicines (DL if dispensing) · Diet & lifestyle info · **Claims moderation** (no cure claims) · Disclaimer "complementary; consult MD for emergencies".
CTAs: Book consult · Book therapy package.

### 2.8 🆕 Dialysis centre
Machines/shifts, **slot calendar** (recurring 3×/week), HBV/HCV/HIV isolation, nephrologist on call, water-RO quality, pricing per session, insurance/PM-JAY, transport help, diet tips.
CTAs: Book recurring slots · Transfer-in request.

### 2.9 🆕 Maternity / IVF
Obstetricians, packages (normal/C-section, antenatal), NICU tie-up, delivery rooms, visiting rules; **IVF**: success-rate disclosure policy (audited data only, ART Act), counselling, cost breakdown, donor program (compliant), ART reg no.
CTAs: Book ANC consult · Request callback.

### 2.10 🆕 Rehab / de-addiction / child-development centre
Programs (duration, residential/day), team (psychiatrist, psychologist, therapist), family involvement, admission process, privacy policy, visiting rules, fees, outcomes (aggregate, ethics-reviewed), helpline. **Discreet mode** (neutral name on statements/notifications).
CTAs: Request assessment · Call.

### 2.11 🆕 Blood bank
Availability by group & component (live/last-updated time), licence, donation camp schedule, how to donate/eligibility, replacement/processing fees policy, 24x7 line, request flow ✅.
CTAs: Request blood · Register as donor · Book donation slot.

### 2.12 🆕 Ambulance operator
Fleet types, coverage area, base + per-km fare calculator, ETA, equipment, driver/EMT credentials (masked), tracking explainer, 24x7 phone.
CTAs: Book now · SOS ✅.

### 2.13 🆕 Gym / fitness centre (T3)
Gallery + virtual tour · Facilities/equipment · **Plans & pricing** (monthly/quarterly/annual, joining fee, freeze policy, refund) · Trainers · Class timetable (yoga, Zumba, HIIT) · **Peak hours/crowd graph** · Women-only hours · Trial pass · Hygiene/locker/shower · Safety (first-aid, AED, fire exit) · Member reviews · Medical-screening note (PAR-Q) · Trainer-certification badges.
CTAs: Get trial pass · Buy membership · Visit (directions).

### 2.14 🆕 Yoga studio / retreat (T3)
Styles · Teachers · **Batch timetable** · Trial class · Packages (drop-in, monthly, 10-class) · Online sessions · Prenatal/therapy batches (with doctor-clearance note) · Camps/retreats (dates, itinerary, stay, food, price) · Certifications (YCB) · What to bring · Cancellation.
CTAs: Book trial · Join batch · Register retreat.

### 2.15 🆕 Wellness centre / spa (T3)
Therapies menu (duration, price) · Therapist profiles & gender options · Hygiene standards · Packages · Gift cards · Policies (no-show, age limit) · **Safety**: consent, contraindications note, no medical-cure claims.
CTAs: Book session.

### 2.16 🆕 Equipment rental / medical-device store
**Catalogue** with rent/buy toggle · Specs · Deposit & rent per day/week/month · Delivery & installation · Sanitisation process · Warranty/repair · Return flow · Demo video · Doctor-prescription requirement notices (O2, CPAP) · Safety instructions.
CTAs: Rent · Buy · Request demo.

### 2.17 🆕 Health-food / supplement / skincare store (T3)
Categories · Brand filters · FSSAI/CDSCO badges · Ingredient/allergen info · Certifications (organic, vegan) · Delivery/returns · **Claims disclaimer** · Rx-only items flagged.
CTAs: Shop · Add to cart.

### 2.18 🆕 Government facility (PHC/CHC/UPHC/Arogya Mandir/Jan Aushadhi)
Address/map · OPD days & timings · **Free services list** (OPD, vaccination, ANC, TB, NCD screening) · Medicines available (Jan Aushadhi list) · Doctor/ANM contact (public) · Helpline · ASHA/Anganwadi link · Schemes info (JSY, PMMVY) · "Information source: govt portal, last verified" · **Claim listing** (staff) · Optional token booking.
CTAs: Directions · Call · Get OPD token.

### 2.19 🆕 Event / camp / workshop page
Banner · Title, type, **date-time, venue map/online link** · Organiser + partner facility (verified) · Agenda · Speakers/doctors · What's included (tests, consult, medicines) · Eligibility (age/gender) · Fee/free · **Seats left, registration deadline** · What to carry/fasting · **Consent & data-use note** · Contact · Photos/outcome report after event · Add to calendar · Share.
CTAs: Register · Add to calendar · Join online.

### 2.20 🆕 NGO / support-group page
Cause, schedule, mode, host, moderation rules, safety/crisis info, anonymity options, how to join, donation (if NGO, 80G).
CTAs: Join · Donate.

### 2.21 🆕 Program / membership page
Program overview, duration, team, what's included, schedule, sample day, outcomes, pricing/EMI, eligibility, medical clearance, FAQs, cancel/pause policy.
CTAs: Enroll · Talk to advisor.

## 4. Data needed per page (public DTO highlights)
`gallery[], description, tagline, establishedYear, ownership, systemOfMedicine, accreditations[], schemesAccepted[], timings{}, amenities[], services[{code,name,price,duration,modes}], practitioners[], packages[], faqs[], policies{}, geo, verification{status,verifiedAt,scope[]}, stats{ratingAvg,ratingCount}`
- Never in public DTO: licence numbers (full), owner phone/email, bank, staff personal IDs, internal notes.

## 5. Interactions & flows from page
- **Book** → BookingModal (file 05) with preselected service/practitioner
- **Call** → click-to-call (optional masked relay), log "call_clicked"
- **Directions** → Maps deep link
- **Save** ✅ → favorites
- **Share** → link with UTM (no PHI)
- **Report** → modal (reason, details) → moderation queue (file 08)
- **Claim listing** → verification flow (OTP to registered phone + docs)
- **Compare** → comparison view (≤3)
- **Ask a question** (P3) → public Q&A moderated

## 6. Edge states
Closed now · Temporarily closed (holiday) · Not accepting bookings · Suspended (404 / "unavailable") · Unclaimed govt listing ("info may be outdated") · No reviews yet · Low-connectivity mode (text-first).

## 7. Security / compliance on pages
- [ ] Public DTO only; `select` explicit
- [ ] UGC (reviews, Q&A, descriptions) sanitized (DOMPurify/sanitize-html), no raw HTML
- [ ] Before/after photos need patient consent + moderation
- [ ] Claim restrictions (cosmetic/weight-loss/sexual-health/IVF success rates)
- [ ] PCPNDT: no gender-determination content on imaging pages
- [ ] Discreet display for sensitive categories
- [ ] Click-to-call & directions don't leak user location without consent
- [ ] Rate-limit report/claim/Q&A endpoints
